# Frontend CRUD Admin Panel

An educational project to develop a UI for backend CRUD operations. The task involved creating an admin panel for managing online game accounts using HTML, CSS, JavaScript, and jQuery. Implemented functionality includes viewing, creating, editing, and deleting records with support for pagination and an interactive interface.
